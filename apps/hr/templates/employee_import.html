1. Unduh template

CSVXLSXBaris pertama = nama kolom, baris kedua = contoh isian (hapus sebelum impor).

2. Isi data

  • Kolom wajib: {% for c in required %}{{ c }}{% if not forloop.last %} {% endif %}{% endfor %}. Kolom lain boleh kosong.
  • department_code memakai kode departemen; position memakai nama jabatan. Keduanya harus sudah ada di Master.
  • shift satu kolom untuk semua jenis shift: GS, GS/N, A7 … G7 (2 shift) atau A7Pack … G7Pack (3 shift/pack). Kode lama (A, A_pack) dan nama shift GS di Master (GS-16/GS-14/GS-12, dibaca sebagai GS) juga diterima.
  • gs_short (14 atau 12) dan off_day (Senin–Minggu) hanya untuk GS dan GS/N. off_day kosong = Minggu.
  • pay_basis: bulanan, harian, borongan, magang_harian, magang_borongan atau prakerin (kosong = bulanan; spasi/strip juga diterima, mis. "magang harian"). grade angka, grade_tier huruf.
  • supervisor_nik = NIK atasan; boleh menunjuk karyawan lain di file yang sama.
  • Tanggal: YYYY-MM-DD atau DD/MM/YYYY. CSV: pemisah koma atau titik-koma, UTF-8.
